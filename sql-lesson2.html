Lesson 2: Creating Tables

SQL allows us to create databases and tables to store our data.

Create Database

CREATE DATABASE School;

Use Database

USE School;

Create Table

CREATE TABLE Students (
    ID INT,
    Name VARCHAR(50),
    Age INT
);

Adding a Primary Key

CREATE TABLE Students (
    ID INT PRIMARY KEY,
    Name VARCHAR(50),
    Age INT
);
