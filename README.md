# 🎓 Online Academy | الأكاديمية الإلكترونية

منصة تعليمية إلكترونية حديثة وتفاعلية لتعليم البرمجة وتكنولوجيا المعلومات خطوة بخطوة، مبنية بتقنيات الويب الأساسية بدون أي أطر عمل خارجية (**Pure Vanilla HTML5, CSS3, JavaScript**).

---

## 🌟 المميزات الرئيسية (Key Features)

- **📚 6 مسارات تعليمية متكاملة:**
  - 🐍 **بايثون (Python):** من الأساسيات إلى الدوال والتحكم في التدفق.
  - ☕ **جافا (Java):** البرمجة كائنية التوجه (OOP) والمفاهيم الأساسية.
  - 🌐 **تطوير الويب (Web Development):** بناء المواقع باستخدام HTML, CSS, JavaScript.
  - ⚡ **سي بلس بلس (C++):** حل المشكلات البرمجية، الخوارزميات، وإدارة الذاكرة.
  - 🗄️ **قواعد البيانات (SQL):** الاستعلامات، الجداول، وتصميم قواعد البيانات.
  - ⚙️ **تطوير الواجهات الخلفية (Backend Development):** الخوادم، الـ APIs، والتعامل مع قواعد البيانات.

- **📈 تتبع تقدم الطالب (Interactive Progress Tracking):**
  - زر تفاعلي لحفظ الدروس المكتملة في كل درس (`Mark as Completed ✅`).
  - حفظ تقدم الطالب تلقائياً في المتصفح (`localStorage`).
  - أشرطة تقدم مئوية تفاعلية وشارات إنجاز في صفحات الكورسات.

- **👤 لوحة تحكم الطالب (Student Profile Dashboard):**
  - إحصائيات حقيقية لعدد الدروس والكورسات المكتملة ونسبة التقدم الكلية.
  - إمكانية تسجيل الدخول وإنشاء حساب ومتابعة التعلم بضغطة زر.

- **🌐 دعم ثنائية اللغة والاتجاه (Bilingual i18n & RTL):**
  - دعم كامل للغتين العربية والإنجليزية.
  - تبديل سلس لاتجاه الصفحة (`RTL` للعربية و `LTR` للإنجليزية).

- **🎬 أنيميشن ومؤثرات بصرية عصرية (Modern Animations):**
  - ظهور العناصر عند التمرير (`Scroll Reveal`).
  - حركة عائمة ثلاثية الأبعاد لصورة الـ Hero وتوهج للعناوين.
  - تأثير زووم وإضاءة فيروزية عند تحويم الماوس على بطاقات الكورسات.
  - وميض لمعة (`Shimmer Light`) على أزرار التفاعل.
  - زر واتساب عائم نابض (`Pulsing Floating WhatsApp`) وزر الصعود للأعلى (`Back to Top`).

- **💬 تواصل مباشر ومتعدد القنوات (Multi-channel Contact):**
  - خيارات سريعة لاختيار المراسلة عبر **واتساب** أو **فيسبوك** أو **إنستغرام**.
  - نموذج إرسال مع إمكانية تحويل الرسالة لتطبيق واتساب مباشرة بضغطة زر.

- **🔍 محرك بحث فوري:**
  - تصفية الكورسات حسب العنوان والوصف مع رسائل توضيحية عند عدم وجود نتائج.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **HTML5:** بناء هيكل الموقع وفق معايير الوصولية القياسية (Semantic & Accessible Markup).
- **CSS3:** تصميم متجاوب بالكامل (Flexbox, CSS Grid, Media Queries, Custom SVG Icons, Keyframes).
- **JavaScript (Vanilla ES6+):** محرك الترجمة، نظام تتبع التقدم، محرك الأنيميشن عند التمرير، وإدارة التخزين المحلي.

## 🚀 تشغيل المشروع محلياً (Run Locally)

المشروع لا يتطلب أي تثبيت لمكتبات خارجية! يمكنك فتحه مباشرة بعدة طرق:

1. **مباشرة عبر المتصفح:**
   - افتح ملف `index.html` في أي متصفح ويب.

2. **عبر خادم محلي (Local HTTP Server):**
   ```bash
   # باستخدام بايثون
   python -m http.server 8000
   ```
   ثم افتح الرابط: `http://localhost:8000`

## 🌐 النشر على استضافة مجانية (GitHub Pages)

المشروع جاهز ومُهيأ 100% للرفع والنشر عبر **GitHub Pages**:
1. ارفع المشروع إلى مستودع جديد على GitHub.
2. اذهب إلى **Settings** > **Pages**.
3. في خانة **Branch** اختر `main` واضغط **Save**.
4. سيعمل موقعك فوراً على رابط عالمي مجاني مثل: `https://<username>.github.io/<repo-name>/`!
