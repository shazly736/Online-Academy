Lesson 2: Variables

Variables are used to store data in a Java program.

Example

String name = "Shazly";
int age = 20;

System.out.println(name);
System.out.println(age);

Output

Shazly
20

Common Data Types

int age = 20;
double price = 10.5;
char grade = 'A';
boolean student = true;
