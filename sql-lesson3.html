Lesson 3: SELECT and WHERE

SELECT is used to retrieve data from a table.

Select All Data

SELECT * FROM Students;

Select Specific Columns

SELECT Name, Age
FROM Students;

WHERE

WHERE is used to filter the data. 

SELECT *
FROM Students
WHERE Age >= 20;

Another Example

SELECT *
FROM Students
WHERE Name = 'Ahmed';
