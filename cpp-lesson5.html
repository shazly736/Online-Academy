Lesson 5: Arrays

Arrays are used to store multiple values of the same type.

Creating an Array

int arr[5] = {10, 20, 30, 40, 50};

Accessing Array Elements

int arr[5] = {10, 20, 30, 40, 50};

cout << arr[0];
cout << arr[1];

Printing All Elements

int arr[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++) {

    cout << arr[i] << endl;

}

Output

10
20
30
40
50

Finding the Sum

int arr[5] = {10, 20, 30, 40, 50};

int sum = 0;

for (int i = 0; i < 5; i++) {

    sum = sum + arr[i];

}

cout << sum;

Output

150
