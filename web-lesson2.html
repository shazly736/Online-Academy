Lesson 2: CSS Basics

CSS is used to style HTML elements and make web pages look better.

CSS Example

h1 {
    color: blue;
    font-size: 30px;
}

p {
    color: gray;
}

Changing Background

body {
    background-color: lightgray;
}

Changing Button Style

button {
    background-color: blue;
    color: white;
    padding: 10px;
}
