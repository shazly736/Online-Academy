Lesson 5: Mini Backend Project

In this lesson we will create a simple Flask backend with two routes.

Complete Code

from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():

    return "Welcome to Online Academy"

@app.route("/courses")
def courses():

    return "Python, Java, C++, SQL"

@app.route("/about")
def about():

    return "Online Academy is an educational website"

app.run()

Routes

/
 /courses
 /about

How It Works

Browser
   |
   v
Flask Backend
   |
   +---- /
   |
   +---- /courses
   |
   +---- /about

This is the basic idea behind building a backend application.
