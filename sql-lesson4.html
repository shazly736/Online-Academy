Lesson 4: INSERT, UPDATE and DELETE

These commands are used to modify data inside a table.

INSERT

INSERT is used to add new records. 

INSERT INTO Students (ID, Name, Age)
VALUES (1, 'Ahmed', 20);

UPDATE

UPDATE is used to change existing data. 

UPDATE Students
SET Age = 21
WHERE ID = 1;

DELETE

DELETE is used to remove records. 

DELETE FROM Students
WHERE ID = 1;
