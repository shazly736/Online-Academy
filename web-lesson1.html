Lesson 1: HTML Basics

HTML is used to create the structure of web pages.

Basic HTML Structure

<!DOCTYPE html>
<html>

<head>
    <title>My Page</title>
</head>

<body>

    <h1>Hello World</h1>

    <p>Welcome to my website.</p>

</body>

</html>

Common HTML Tags

<h1>Heading</h1>

<p>Paragraph</p>

<a href="index.html">Link</a>

<button>Click Me</button>
