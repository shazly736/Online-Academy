Lesson 5: JOIN

JOIN is used to combine data from two or more tables.

Students Table

Students

ID    Name
1     Ahmed
2     Sara
3     Ali

Courses Table

Courses

StudentID    Course
1            Python
2            Java
3            C++

INNER JOIN

SELECT Students.Name, Courses.Course

FROM Students

INNER JOIN Courses

ON Students.ID = Courses.StudentID;

Result

Name       Course
Ahmed      Python
Sara       Java
Ali        C++
