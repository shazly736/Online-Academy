Lesson 5: Mini Web Project

In this lesson we will create a simple interactive counter using HTML, CSS and JavaScript.

HTML

<h1 id="number">0</h1>

<button onclick="increase()">
    Increase
</button>

JavaScript

let number = 0;

function increase() {

    number++;

    document.getElementById("number").textContent = number;

}

Complete Example

<!DOCTYPE html>

<html>

<body>

<h1 id="number">0</h1>

<button onclick="increase()">
    Increase
</button>

<script>

let number = 0;

function increase() {

    number++;

    document.getElementById("number").textContent = number;

}

</script>

</body>

</html>
