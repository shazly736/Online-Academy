Lesson 4: Loops

Loops are used to repeat a block of code.

For Loop

for (int i = 0; i < 5; i++) {

    cout << i << endl;

}

Output

0
1
2
3
4

While Loop

int i = 0;

while (i < 5) {

    cout << i << endl;

    i++;

}

Sum from 1 to 5

int sum = 0;

for (int i = 1; i <= 5; i++) {

    sum = sum + i;

}

cout << sum;

Output

15
